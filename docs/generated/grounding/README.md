# Generated Grounding Snapshots

This folder contains machine-generated outputs produced by grounding evaluation wrappers.

These files are summary snapshots. Raw per-run evaluation outputs live under
`docs/generated/ground_truth/grounding_only/`.

## Expected files

- `ground_truth_vector_grounding_milestone.md`
- `ground_truth_vector_grounding_persistent_error_manifest.json`
- `ground_truth_vector_runs_manifest.jsonl`
- `ground_truth_vector_runs_manifest.csv`

## Producer

Generated by:

- `slurm/gt-eval-vector.sbatch`
- `scripts/generate_grounding_progress_report.py`
- `scripts/generate_vector_grounding_milestone.py` (compat alias)

Do not manually edit generated files. Update the producing scripts or wrappers instead.
